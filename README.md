# RcloneView – selbst verwalteter Google-Drive-Zugang

Diese Seite beschreibt eine selbst verwaltete OAuth-Konfiguration
für den Zugriff auf Google Drive mit RcloneView und rclone.

Der Zugang dient der betrieblichen Dateiverwaltung durch berechtigte
Personen. Er ermöglicht das Anzeigen von Ordnern und Dateien sowie
das Übertragen und Verwalten von Dateien im verbundenen Google-Konto.

## Google-Anmeldung und Berechtigungen

Die Anmeldung und Freigabe erfolgen über Google.
Die eingerichtete Drive-Berechtigung erlaubt das Lesen, Erstellen,
Bearbeiten und Löschen von Dateien.

Diese Informationsseite enthält keine Google-Anmeldefunktion.
Zugangsdaten, Anmeldetoken und Drive-Dateien werden hier nicht
veröffentlicht.

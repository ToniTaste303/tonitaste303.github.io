Diese Hinweise beschreiben den technischen Google-Drive-Zugriff über die eigene OAuth-Konfiguration mit RcloneView und rclone sowie diese Informationswebsite.

2. Zweck und zugängliche Daten

Der Zugang dient der betrieblichen Dateiverwaltung durch berechtigte Personen. Verarbeitet werden je nach ausgeführter Aktion Ordner- und Dateinamen, weitere Dateiinformationen wie Größe und Änderungsdatum sowie Dateiinhalte. Bei der Anmeldung werden außerdem OAuth-Anmeldetoken verarbeitet.

Die freigegebene Berechtigung https://www.googleapis.com/auth/drive ermöglicht das Anzeigen, Herunterladen, Hochladen, Erstellen, Bearbeiten und Löschen von Dateien im verbundenen Google-Konto.

3. Verwendung und Übertragung

Die Daten werden verwendet, um die von berechtigten Personen veranlassten Datei- und Ordneroperationen auszuführen. Die Anmeldung und Freigabe erfolgen über Google. Die Dateioperationen erfolgen über die Google-Drive-API.

Bei Downloads gelangen Dateien auf die dafür ausgewählten Rechner oder Speicherziele. Bei ausdrücklich eingerichteten Übertragungen an weitere Speicheranbieter werden die dafür ausgewählten Dateien an das jeweilige Ziel übertragen.

Dieser Zugang dient nicht dem Verkauf von Google-Nutzerdaten oder deren Verwendung für Werbung. Für die Nutzung gelten die Google API Services User Data Policy einschließlich ihrer Limited-Use-Anforderungen.

4. Speicherung und Entfernung

OAuth-Anmeldetoken werden in der lokalen Rclone-Konfiguration gespeichert. Abhängig von den Einstellungen können auf den eingesetzten Rechnern außerdem Zwischenspeicher und Protokolldateien entstehen.

Die Anmeldedaten bleiben gespeichert, solange die betreffende Konfiguration aufbewahrt wird. Zwischenspeicher werden gemäß den eingestellten Cache-Regeln verwaltet. Bewusst gespeicherte Dateikopien bleiben bis zu ihrer jeweiligen Löschung am ausgewählten Speicherort erhalten.

Die Google-Zugriffsfreigabe kann unter Google-Konto: Verbindungen zu Drittanbieter-Apps widerrufen werden. Ein Widerruf entfernt bereits gespeicherte Dateikopien und lokale Zwischenspeicher nicht automatisch. Für deren Entfernung wende dich an die oben genannte Kontaktadresse.

Diese statische Website wird über GitHub Pages bereitgestellt. Sie enthält keine Google-Anmeldung, keine Formulare und keine vom Betreiber eingebundenen Analyse- oder Werbeskripte. Google-Anmeldetoken und Drive-Dateien werden auf dieser Website nicht veröffentlicht.

Beim Seitenaufruf verarbeitet GitHub technische Zugriffsdaten, darunter die IP-Adresse. Weitere Informationen enthält die Datenschutzerklärung von GitHub .
